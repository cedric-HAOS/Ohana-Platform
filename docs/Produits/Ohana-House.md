# Ohana-House

Ohana-House documente le déploiement domestique de référence de l'écosystème
Ohana.

Le dépôt distingue :

- l'infrastructure actuellement déployée ;
- l'architecture cible Hashirama ;
- les migrations encore à réaliser.

Il contient les plans d'adressage, l'inventaire, les décisions d'architecture,
les procédures d'exploitation et les diagrammes de la maison.

Ohana-House ne duplique pas les contrats logiciels :

- Agent reste propriétaire de la configuration opérationnelle ;
- Vision présente et administre cette configuration via Agent ;
- Platform définit la composition publiée ;
- Installer applique cette composition sur Linux/systemd.
