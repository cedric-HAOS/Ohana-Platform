# Guide d'installation de production

Suivre [le guide nominal Platform](../Installer-Ohana-Platform.md) : préparation
d'Installer, sélection dans le catalogue, confirmation du plan et contrôle des
versions effectivement installées.

Le [guide Installer](https://github.com/cedric-HAOS/Ohana-Installer/blob/main/docs/Installation.md)
décrit les téléchargements officiels et les contrôles SHA-256. Pour une
restauration INFRA-01, utiliser Installer 1.15.6 ou supérieur.

Le [guide de développement](../getting-started/Installer-Ohana-Platform.md)
reste distinct de ce parcours de production.
